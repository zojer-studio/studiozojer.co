Updated from iOS 17.0 -> iOS 18.0 to support modern navigation patterns.

New
- Decan fingerprints and codex entries — search for decans in the codex using roman numerals (e.g., "Leo I", "Moon Leo II")
- Added Modern decan system — uses outer planet rulers (Uranus, Neptune, Pluto) with triplicity rotation, available alongside Chaldean and Triplicity in display profile settings
- Fixed triplicity decan rulers — each sign's first decan now correctly uses its own ruler (e.g., Leo I = Sun, not Mars)
- New "Transits" display profile — optimized for bi-wheel and tri-wheel transit charts, showing angles and points (Asc, Desc, MC, IC, Fortune, Spirit, Vertex) on the natal ring only while keeping outer transit rings clean

Bug fixes
- Fixed chart positions off by up to ~15 arcminutes — the date picker only captures hours and minutes, but seconds from the current clock time were leaking into saved birth times, shifting fast-moving points like the Ascendant
- Fixed lunar mansions ring positioning for tropical charts — nakshatras and manzils now render at their correct sidereal positions regardless of zodiac system setting
- Fixed Min Inner Radius stepper in display profiles — the stepper was writing to the base setting, which was immediately overridden by the per-ring-count variant, making the control appear unresponsive
