The Patterns chip in global search is now live. The Rust-side codex search has been there since February — type something like "sun gemini", "mars aries 4h", "jupiter trine venus", or "venus rx" and the matching patterns surface as a new section above hubs and charts. Tap to open the pattern page.

Changes
- Patterns filter chip enabled in global search
- New "Patterns" section in the results list, capped to 5 in browse-overview mode with a "See all" footer
- Each row shows the pattern title plus a brief match reason; tap routes to the pattern detail page
- Empty-state guard updated so "No results" only appears when patterns, hubs, and charts are all empty
