This release is mostly about the display controls — they've been regrouped and reorganized, and should be a lot easier to navigate now.

**New customization options**
- Invert glyph order
- Double-tick option for the planets ring

**Fixed stars**
- Added sorting options to the library, plus some UX cleanup

**Presets**
- Cleaned up the default profiles — you may want to reset them in Settings to pick up the changes
- Updated the preset on the today page

**Also in this build**
- Fixed several bugs with the vault
- General code-quality improvements
- Minor bug fixes

**Experimental**
- Trying out a new global setting that hides AC/MC/DC/IC, lots, vertex, and similar points from the outermost ring (for cleaner transit charts)
