The Dashboard tab got a substantial redesign with a new week view, a restyled month view, and a time-grid day detail.

New
- Week view — scrollable 24-hour grid with 7 day columns, activation blocks positioned at their exact transit times. Overlapping activations stack vertically so every block keeps its full width and glyphs stay readable
- Month/week toggle in the dashboard header
- Month picker row — horizontally scrollable months with year separators, matching the Google Calendar pattern. The present month gets an outline indicator even when another month is selected
- Day detail — replaced the list view with a 24-hour time grid showing full-width activation blocks (glyphs + text label + exact time)
- Red "now" marker — horizontal line on today's column (week view) and on today's grid (day view) showing the current time
- Auto-scroll to first activation — both week and day grids scroll to one hour before the first activation on appear
- Double-tap the page title to jump back to the present date and time. In week view, the time grid animates to the current hour
- Aspect glyphs in activation blocks are now color-coded by aspect type (trine blue, square orange, conjunction red, etc.)

Changes
- Month view redesigned as a flat edge-to-edge grid with thin dividers, day numbers top-left, and activation pills left-aligned
- Dashboard header follows the standard tab pattern (title on the left, actions on the right)
- Moon transits are filtered to conjunctions only by default to reduce calendar noise
